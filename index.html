This course is a year-long senior project: students build a real product of their own choosing, run the way real software teams work.

The year opens with a whole-class infrastructure kickoff before anyone pitches an idea: everyone deploys a real chat app, first alone, then together on a shared machine. From there it moves through ideation, research, and build sprints with real code review. Sprint 1 starts before the second board meeting, so that meeting is a working prototype demo, ending in a production launch and Demo Day. AI is part of how this class works, not a shortcut around it: think first, spec what you want, and understand what it writes.
